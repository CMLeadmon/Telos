# Telos 0.1.0-beta.1 Certification Specification

Beta certification is not implemented or claimable in the current repository.
`scripts/certify-beta.sh` deliberately returns `not_run` (exit 3) until Phase 5
supplies the candidate certification workflow and its evidence.

## Required Certification Gates
1. Candidate-bound master verification evidence.
2. Security, Vulnerability, and License SBOM Audit.
3. Runtime Hardening and Container Exposure Verification.
4. Clean-Node Installation, Upgrade, and Rollback Drills.
5. Disaster Recovery and Backup Retention Drills.
6. Supported Browser Matrix & WCAG 2.2 AA Accessibility Audit.
7. Capacity Benchmark & External Network Exposure Audit.
