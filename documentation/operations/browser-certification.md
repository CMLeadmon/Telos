# Telos Supported Browser and Responsive Certification Guide

This document defines the certification rules for supported browsers, mobile viewports, and physical devices across Telos.

## Matrix Cells
- Google Chrome (Stable)
- Mozilla Firefox (Stable >= 152.0.6)
- Microsoft Edge (Stable)
- WebKit (Playwright automation)
- Mobile Chrome / Mobile Safari Emulation
- Physical iOS Safari / Android Chrome
